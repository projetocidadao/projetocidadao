# Princípios do Projeto Cidadão

> "Tudo que precisamos já foi criado — só está espalhado ou desencontrado."
> — visão fundadora do projeto

O Projeto Cidadão nasce da convicção de que a sabedoria necessária para uma sociedade justa, transparente e funcional já foi pensada, ensinada e praticada ao longo da história humana. O papel da tecnologia não é inventar novos valores, mas **reunir, organizar e dar acesso** ao que já existe.

A fonte de inspiração declarada deste documento é **Confúcio (Kong Qiu, 551–479 a.C.)** — escolhida por ser a mais antiga entre as grandes tradições filosóficas, mantendo atualidade milenar.

---

## Os 6 Princípios

### 1. Humanidade (Ren 仁)
Tratar o outro como gostaria de ser tratado. O sistema é construído para servir pessoas, não o contrário.

### 2. Retidão (Yi 义)
Fazer o que é correto, não o que é conveniente. Código aberto, dados auditáveis, decisões transparentes.

### 3. Honestidade (Xin 信)
Palavra cumprida. O que o sistema declara fazer, faz. O que registra, é o que aconteceu.

### 4. Rito (Li 礼)
A forma visível do respeito. Interface clara, linguagem acessível, processo documentado.

### 5. Sabedoria (Zhi 智)
Distinguir o certo do errado. Cada cidadão tem direito a informação que permita discernir.

### 6. Cultivo Contínuo
Nada está pronto. O sistema evolui com o uso, com o erro reconhecido, com a correção pública.

---

## Aplicação concreta no sistema

| Princípio | Onde aparece no código |
|---|---|
| Humanidade | Denúncias anônimas, proteção do denunciante, acessibilidade |
| Retidão | Código aberto, logs auditáveis, LGPD como direito |
| Honestidade | Nota de transparência em toda denúncia removida |
| Rito | Swagger público, README claro, schemas documentados |
| Sabedoria | Cursos colaborativos, educação para cidadania |
| Cultivo | Issues públicas, changelog honesto, sem esconder bugs |

> — *Regra de ouro, séculos antes de Cristo*

> "O homem superior busca o que é reto; o homem inferior busca o que é vantajoso."
> — Sobre retidão (Yi) acima do interesse pessoal

> "Uma vez que o homem se engana a si mesmo, não há caminho que o leve à verdade."
> — Sobre honestidade intelectual como base

> "Se governares com leis e punições, o povo fugirá delas e perderá o sentido de vergonha. Se governares com virtude e decoro, o povo terá vergonha e se corrigirá."
> — Princípio fundador da transparência por cultura, não por vigilância

> "Quanto mais medito, mais o meu pensamento se aprofunda; quanto mais aprendo, mais a minha ignorância se revela."
> — Sobre o cultivo contínuo e a humildade epistêmica

> "Não darei instrução a quem não estiver movido por grande ansiedade de aprender."
> — Sobre o valor do engajamento ativo do cidadão

## O que este documento **não** é

- Não é código. É a bússola que orienta o código.
- Não é doutrina fechada. Está aberto a contribuição, com o mesmo rigor.
- Não é lista de features. Princípio vira feature quando faz sentido; feature sem princípio é refatorável.
